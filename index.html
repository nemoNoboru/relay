Deploy

Online in one command

Works on this node, right now — no sign-up, no permission slip. Get a key, pack the folder, upload: the site is live at /<node>/<site>/ before you can refresh.

01

Get a key

A deploy key is the deed to your site. Ask this node's operator for one — or, if the node is yours, issue it yourself on the admin console.

Open the admin console
Ten seconds · no sign-up
02

Pack the folder

Archive the folder's contents, not the folder itself. Every upload replaces the whole site, atomically.

tar -C ./dist -cf site.tar .
Relative paths · ≤ 256 MiB
03

Upload

curl -X POST \
  -H "Authorization: Bearer $RELAY_DEPLOY_TOKEN" \
  -H "Content-Type: application/x-tar" \
  --data-binary @site.tar \
  "$RELAY_ORIGIN/_relay/v1/sites/docs/deploy"

$RELAY_ORIGIN is this node's address · $RELAY_DEPLOY_TOKEN is your deploy key

Run a node

Your machine,
a web server

Relay is one binary. Install it and start a node — the same code hosts sites, hands out keys, and keeps every byte of state in one directory you own.

01

Binary

curl --proto '=https' --tlsv1.2 -sSfL \
  https://raw.githubusercontent.com/nemoNoboru/relay/main/install.sh | sh

relay node --data /var/lib/relay --listen :8080
Linux · macOS · amd64 · arm64
02

Containers

docker run -d -p 8080:8080 -v relay-data:/data \
  ghcr.io/nemonoboru/relay:latest

Kubernetes is one kubectl apply away — see the technicals.
