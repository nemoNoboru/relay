What is Relay?

Somewhere to put your website that nobody owns. The page you are on belongs to a server someone keeps running — a collective, a club, a neighbour — not to a company. Drop your files above and they are online. There is no account to make, nothing to install, and no bill at the end of the month.

Why not just use a platform?

Because you would be renting. The big hosts own the ground your site stands on: they set the terms, change them when it suits them, count every visitor, and can take the whole thing down without telling you why. What you built is only yours for as long as they allow it.

Here the arrangement is plain. Your site is a folder of files on a machine a person you can actually talk to looks after. No tracking sits between you and whoever reads it. If you ever want to move, you take the same folder somewhere else — there is nothing to export and nothing holding it.

What can I put here?

Pages, pictures, a zine, notes, a poster for something happening on your street. If all you have is a single Markdown file, drop that: it is turned into a page for you. Each upload replaces the whole site, and the last ten versions are kept in case you want one back.

Want one of these servers of your own? Anyone can run a node — it is one program on any computer, an old laptop included.

For AI assistants

Using Claude or another assistant? Copy this, paste it into the chat, and tell it where your site is.

You were sent a link to this page. The deploy key is the key value after # in that link; never print it or send it anywhere else. To publish, send a tar of the site to this server: 

tar -cf - -C SITE_FOLDER . | curl --data-binary @- \
  -H "Authorization: Bearer KEY" \
  https://THIS-SERVER/_relay/v1/sites/SITE_NAME/deploy

THIS-SERVER is the host of the link. Site names are lowercase letters, numbers and hyphens. The JSON reply's url field is the site's address. Each upload replaces the whole site. More detail: the publishing instructions.
